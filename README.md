## 目前能跑出什么

`第十一天/10.py` 是一个**配置驱动的词频统计器**：

- 读 `config.json` 决定语言、显示条数、停用词表路径
- 中文走 jieba 分词，英文走 `split()`
- 文件不存在 / 编码不是 UTF-8 / 文件为空，各有对应的异常和提示

跑 249 字的中文语料，输出：

```
配置：语言=zh，显示前 8 名，停用词 47 个
====================================
文件：../data/sample_zh.txt（zh）
总词数：84    不同词数：56
====================================
 1. 质量           6    7.1%
 2. 检索           6    7.1%
 3. 模型           4    4.8%
 4. 文档           4    4.8%
 5. 提示词          4    4.8%
 6. 回答           4    4.8%
 7. 上下文          3    3.6%
 8. 问题           2    2.4%
```

## 怎么运行

需要 Python 3.11+。

```bash
# 1. 克隆
git clone git@github.com:2966105441/ai-roadmap.git
cd ai-roadmap

# 2. 装依赖（走国内镜像，默认源拉 20MB 的包经常超时）
pip install jieba -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 跑词频统计器
cd 第十一天
python 10.py
```

> 注意：`10.py` 用相对路径读 `../data/`，**必须在 `第十一天/` 目录下运行**。
